# C Practice

A personal repo for daily C programming practice, organized by topic.

## Structure
- `01_variables/` - variables, data types, basic I/O
- `02_loops/` - for, while, do-while
- `03_functions/` - function declarations, recursion
- `04_arrays/` - arrays, strings
- `05_pointers/` - pointers, pointer arithmetic
- `06_structs/` - structs, nested structs

## Workflow
1. Write a new .c file in the relevant folder, named by day/topic (e.g. `day1_sum.c`)
2. Compile: `gcc folder/file.c -o output`
3. Run: `./output`
4. Commit: `git add . && git commit -m "Day X: topic"` then `git push`

## Setup
```
git clone https://github.com/yourusername/c-practice.git
cd c-practice
gcc 01_variables/hello.c -o hello
./hello
```
